# ChessMaster — платформа онлайн-курсов по шахматам

Веб-приложение для продажи и прохождения шахматных курсов с тремя ролями пользователей: студент, преподаватель, администратор (в рамках курсовой работы по разработке интернет-приложений)

## Стек

**Backend:** Go, Gin, GORM, PostgreSQL, JWT, Swagger (swaggo/swag)
## Функциональность

- **Аутентификация и авторизация** — JWT, ролевая модель (student / teacher / admin)
- **Каталог курсов** — фильтрация по уровню сложности и тематике, поиск
- **Управление курсами (admin)** — CRUD операции с курсами и категориями
- **Заявки на курсы** — студент оставляет заявку → преподаватель одобряет/отклоняет → студент оплачивает → получает доступ
- **Прохождение курса** — модули, уроки, отслеживание прогресса
- **Swagger-документация API**

## Тестирование

Backend покрыт интеграционными тестами (регистрация, логин, CRUD категорий, заявки на курсы). 

## Запуск

\`\`\`bash

cd server
go run cmd/main.go
